# Die Trying

A simple game about rolling dice, upgrading dice, and raging at dice. Not much else to say... Just don't roll 1s.

There is also a LITE version, made to run on Casio FX-CG100 Graphical Calculators:
https://github.com/pianoplayer1224/Die-Trying-LITE

## How to Play

Click the die to roll it.

- Every roll adds its value to your **Progress**. Reach **500** to win.
- Every roll also earns **Money** equal to the number rolled.
- **Roll a 1 and your progress is wiped.** The money you have already banked
  is safe — only progress is lost.
- Roll the same number twice in a row to start a **MATCH STREAK**. Every roll in
  the streak pays bonus money, and the bonus keeps growing the longer the streak
  runs.

### Upgrades

Money buys four things, each of which can be upgraded several times:

| Upgrade | What it does |
| --- | --- |
| **Dice** | A bigger die: d2 through d20 |
| **Speed** | Faster rolls, less waiting |
| **Money Mult** | Multiplies everything you earn |
| **Match Bonus** | Makes match streaks pay far more |

A bigger die rolls higher numbers and busts less often, but matches get rarer
as the faces go up — the humble d2 matches on almost every roll.

Reaching the goal wins the game, or you can then choose to **Keep Playing**
and carry on forever.

## Saving

There is no save file: your game is a ten-character **save code**, found under
**Options → Save Options**. The screen always shows the code for the game in
progress — write it down, and type it back in later to pick up where you left
off. Codes work across the original and LITE editions.

The same screen holds the **Reset Game** button, which starts a fresh run.
